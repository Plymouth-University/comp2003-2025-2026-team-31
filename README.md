# 🎨 ArtoFest – Festival Discovery Platform

## 📌 Overview

ArtoFest is a web-based platform designed to help users discover art and cultural festivals around the world. The application allows users to explore festivals by location, view detailed event information, and access booking options for travel, accommodation, and tickets.

This project was developed as part of a group coursework, with a focus on user-centered design, collaborative development, and full-stack implementation.

---

## 🚀 Features

* 🌍 **Explore Festivals** – Browse festivals by country or region
* 🗺️ **Map View** – Interactive map showing festival locations
* 🔍 **Filter & Search** – Find festivals based on preferences
* 📄 **Festival Details** – View event descriptions, dates, and highlights
* ✈️ **Booking Integration**

  * Travel (affiliate links)
  * Accommodation (affiliate links)
  * Tickets (redirect to official festival sites)
* 👤 **User-Friendly Interface** – Clean and responsive design
